# Interactive Personal Data Collector

## 📌 Project Overview

The **Interactive Personal Data Collector** is a simple Python project that collects basic information from the user and displays the entered data along with its Python data type and memory address.

The project also calculates the user's approximate birth year based on their age.

## ✨ Features

- Takes the user's name as input.
- Takes the user's age as input.
- Takes the user's height as input.
- Takes the user's favourite number as input.
- Displays the collected information.
- Shows the Python data type of each value.
- Shows the memory address using `id()`.
- Calculates the approximate birth year.
- Displays a goodbye message at the end.

## 🛠️ Technologies Used

- Python 3
- `input()` for user input
- `int()` and `float()` for type conversion
- `type()` to display data types

## 💻 Example

The program asks for:

- Name
- Age
- Height
- Favourite number

It then displays the collected information, its data types, memory addresses, and an approximate birth year.
